# Third-party notices

## LiveKit client SDK

The browser bundle at `vendor/livekit-client.umd.js` is derived from the LiveKit JavaScript client
SDK.

Its upstream license is preserved at
[`vendor/LICENSE.livekit-client`](vendor/LICENSE.livekit-client).

Before updating the bundle, verify the upstream release, integrity, browser compatibility, and
licensing terms. Remote runtime scripts are intentionally not used because Chrome Manifest V3
requires extension code to be packaged with the extension.
